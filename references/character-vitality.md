# 人物生命力：独立推演、缺失场景与纵向审读

适用于重大关系场、人物同质化、初写动机冲突或长篇深修。通用原则与验收以[三层六维](six-dimension-quality.md)为准；本文件提供操作方法。普通日常不必完整加载本文件；所有例子均为原创合成，不是实际小说原文或已验证效果。

## 独立推演不是替人物讲道理

锁住当前事实、人物所知、身体条件、关系阶段和作者已定结果。先不问“怎样写出大纲规定的行动”，问“如果结果没有被作者预先写好，这个人在此刻最想做什么？”。分别取人物的长期愿望、此时最在乎的人、当前利害、经验和偏见、身体与情绪。只取相关因素，不对所有人填全表。

把三个层次分开：本人觉得应该做的事、本人实际上想做的事、眼前真能做到的事。三者可以一致，也可以错开。允许某人正确理解对方仍然埋怨、愿意帮忙却不肯原谅、做错事但不觉得错、先保护亲近者后才考虑公正。反过来，善于沟通、经验丰富、确实平静的人可以保持原样。

关键场若既定动作与推演冲突，先改实现路径：谁先开口、谁先采取行动、阻力来自何处、怎样被迫退让、是否能够保留尚未解决的态度。不得借独立推演推翻作者锁定的结局；若可行路径全部与已定事实矛盾，具体列出矛盾与候选，处理其余已授权内容。

例如：甲得知多年好友乙要冒险，大纲要求甲去找帮手。甲可能先抓住乙追问，发现拦不住才去寻找帮手；也可能冷静地立即找人，因为她此前已知拖延会致死。哪一种成立取决于此前正文，不预设每个朋友都要抓手、哭泣或发火。若大纲仅锁定找到帮手的结果，不把中间每步当硬约束。

## 情感充分性与不完美行为

从人物亲历的关系而非事件标签判断重量。五个观察位置：触发前的愿望/未解心事；第一次确知的时刻；当场行动与未出口的冲动；随后能否回归生活；下一次实际相处。可跨场、跨章分配，不要求五处全部出现。先核实人在不在、知不知道、能不能做，再谈反应。

**感受、表达、行为、反省、修复各自有时间。** 比如两人吵架，甲可以当场道歉仍觉得委屈；乙接受道歉但不想再谈；第二天二人一起买菜并不代表信任已完全恢复。也可以有真正而快速的和解。不要把情绪迟延当通用配方，更不要给每次错误追加惩罚。

危急时行动可能压住情绪，但不因此自动抹掉私人反应。读者应在当时或后续合适时点有机会感受其重要性。若人物故意保持沉默，区分想克制、能够克制、读者能读出什么，而不是用一段旁白宣告他很痛苦就过关。喜悦同样需要考察：愿望实现时可能想分享、独自庆祝、得意或一时不敢相信。快乐不必兼任悲剧伏笔。

## 表达习惯的纵向校准

沿用[语言行为档案](character-templates.md#语言行为档案沿用个人卡)。选取早期、关系改变的关键期及当前可比场景，引用本人完整交谈及当前视角的心理段；不拿危急口令与熟人夜谈直接对比。考察主动起话、持续话题、倾诉范围、玩笑、详略、应对误解、情绪外露、内在活动与说出口的落差。变化标明来源：关系变近、生活经验、处境变化，还是无依据漂移。

寡言不等于无话可说。话少但心理丰富的人，内心可以包括普通审美、回忆、小期待、嫌弃、好奇、对他人的误判、自得和被打断的联想；这些不总服务于当下事件。熟人面前可以主动讲很久，特别开心或失控时也可能反常。整体仍应与更健谈的人有所区别，不能只在首登表现寡言。若人物是当前视角，允许完整的私人思维停留；非当前视角只能写可观察迹象或合理推测，必要时按授权调整场界与视角。

合成示例：寡言的甲听朋友说晚饭不来了，答“行”。甲心里惦记冰箱里两人份的菜，后来把其中一份分给邻居。也可能她原先就想独处，反而高兴。两者均须由前文期待支持。无需强行把心理写成一段道德分析或连续“想说又没说”。若前文明示这天两人没有约好，也不能把朋友写成失约者。

在群像纵向复核时，先比较相同角色的不同阶段，再比较不同角色在相近情境的表现。普通短答可共有；识别的是一段完整相处中的行为与注意力，而非每句都能盲猜姓名。统计仅可辅助找异常位置，不按比例自动删对白。

### 对照示意：不要用理性结论替人物体验

材料（合成）：甲平日寡言但心思细密，与乙相交多年，期待一起去看一场展览。乙刚说今晚可能得进入危险区域，事后才能赴约。已定结果是乙仍要出发，甲最终去找援手；此时并不知道具体死亡风险。

问题写法：“我知道你有必须做的事。”甲点点头，“我尊重你的决定。我去找人帮你。”此段逻辑通顺，却没有此前关系与甲的私心，且在情绪形成前就让她处理妥当。

可用的另一种过程（只示意，不作模板）：

> “非今天不可？”
>
> 乙说那边已经来电话了，等不得。
>
> 甲看着鞋柜旁那两张票。她昨天还专门查过末班车的时间。怎么什么事都等不得呢？上次也是，乙说去一趟，很快，回来的时候衣服都干透了，人却还在发抖。
>
> “我跟你去。”
>
> 乙不答应。两人在门口站了一会儿，甲先把包放下，去拿手机。她知道有个人也许能拦住乙。她并不想让那个人去劝乙小心些。她想让他别放乙进去。

改法的收益不在多几句心理，而在于甲的私人愿望改变了实际行动：仍然去找援手，却不是立即接受结果。若前文明确甲已在共同计划中作过充分准备、乙此刻离开是唯一救人条件，则原有冷静处理可能更成立；需要回读证据，不照抄这里的反应。若原稿采用乙的限知视角，不得直接插入甲的私念。

## 主动发现缺失场景

对于关键事件，按以下短流程审读；无需逐一对所有章节展开正式报告。

1. 找到触发点及相关人物，读事件之前的关系原文和实际时点。先按人物自身推演有证据支持的可能反应，不依赖事后解释或旧验收结论。
2. 回到实际正文，检查该人物当时是否已知、有无行动条件，原稿在哪里写了行动、心理、沉默、延迟反应或普通生活；再查之后是否有兑现。涉及读者已知而角色不知的事实，必须按获知时间分别判断。
3. 给出判断：**已充分承载**、**有效留白/延迟**、**确有缺失**、**材料不足待核**。可能存在另一种反应不等于原稿错。缺失要能解释读者为何读不出关系分量、行为为什么突兀、后文为什么像情感归零。留白也须说得出其具体叙事作用。
4. 按影响选择：补当前场的真正反应；完整重写；另设独立场景；将被挤走的余波移到合适的时间；前移已有生活铺垫；或重组章群。只修局部即可成立时不大改。若需要重大新情节、爱情成立、秘密或能力，不能自行升级授权。
5. 新稿与前后场连读：是否只是增加哭喊、心理总结或任务步骤？是不是所有人都在同一时刻轮流表态？新增片段是否挤掉了已有精彩日常，或制造新的事实冲突？证据不支持就调整或撤回。

**缺失如何留证**：触发位置 + 关系/性格原文位置 + 原稿实际反应及后续位置 + 为什么不足（或为什么留白成立） + 处理尺度 + 复读状态。可合并在已有章群问题记录，无需另建每章表格。没有正文、仅有摘要时只能给候选问题，不能断言缺失。诊断时不写回；对白专项发现结构性缺失仅记越界问题，不自行补戏。

## 双轨因果和章群重构

事件行为链回答事情如何改变现实与下一步行动；情感关系链回答人在事情之后怎样看待彼此、是否期待见面、旧情绪怎样侵入普通生活。二者允许交叉和不同步。不以新调岗、赔偿、材料移交代替情感后果；不让日常变成每段都须回收的线索。

先把完整章群按实际阅读顺序列出场景与各自的体验，定位关系源头、触发、结果、后续可比相处。标出精彩生活、合理留白、硬设定；再找信息重复、情感重复、关键经历只剩提要、数章气氛和收束同构的位置。若问题在章群布局，换场入口、移动或补足有分量的情绪过程、合并重复场或重排叙事重心，而非逐章增加心理。章界、题名、视角与重大因果按项目授权，不擅删群像。

改后先从章首读完整新稿，再沿两条链复读本单元与必要邻章，远端相关点按实读覆盖记录。人物线跨越整个长篇时，需要回访早期与后期的关键关系及可比表达；定向样本不能冒充所有章节通读。真正全书终验须在最新累计稿上完成完整连续阅读并复核重点人物纵向轨迹。后文未写则记待兑现，不宣布已闭合。
