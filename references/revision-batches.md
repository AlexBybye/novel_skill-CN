# 连续章节与全量精修的批次执行

综合精修与文学验收执行[三层六维 V3.1](six-dimension-quality.md)。只读审时按章群提供证据；专项只处理获准的维度。

用于连续多章、全书回修或跨对话继续同一轮任务；单句修改不建立批次。执行本次作者指定的范围和顺序，已给全量授权不重新退回少量试验，也不因某章旧记录写着“已修”而跳过。

## 先固定当前版本和这轮要做什么

在作品已有任务或章节变更记录中注明起止范围、所用稿件、这轮具体标准、不可改事实与实际停点。记录日期、执行者、实际加载的技能路径与版本，便于识别旧安装副本。沿用项目的Git、备份和暂存约定；作者已要求不留修前副本时不因通用流程再复制。不要复制一套人物库、再建一套永久剧情账本，或新造每章一个报告。

已有作者亲修稿、累计修订稿和历轮意见时，分别确认作者认可的事实与文本基线、作为唯一施工基线的最新累计正文，以及每批意见针对的历史版本。用实际文件建立覆盖索引，核对章名、插章、阅读顺序与叙事时序。未完稿以本次实际写出且获授权的章节为边界，当前末章按其在故事中的阶段判断。

围绕完整场景比较作者基线和当前稿。先核对作者最新裁定，再判断旧意见在现稿中是仍成立、已修复、已被裁定排除，还是因资料不足待核。遇到版本冲突回查两稿和相关原话，保留后续确有收益的修订。旧改力度不足时继续修，削薄人物、节奏或因果的改动可局部撤回或重写。缺少比较底本时标明证据范围，仍可在授权内处理能由现稿确认的问题。历史报告和差异统计用于定位与追踪。

规划、资料、正文和摘要分别判断：最终采用的规则由作者决定，角色知情与物品伤势从对应时点的实际稿核对。先看章群里读者正在等什么、哪些线已有阶段答案，再逐场处理；不能把全书流程压成逐章查标点。

## 按实际叙事单元处理

内部处理以相连场景、事件或关系过程划分。作者指定正式审核批次时，按其口径统计正章与插章，内部处理单元仍以完整叙事过程为准。跨章对手戏应连读；隔得很远却相关的伏笔可取必要上下文补核，按实际阅读范围记录。已有整批授权时按连续范围推进，内部单元结束后从实际停点接续。

先定位这段的实际问题层：因果与设定、人物连续状态、交谈过程、读者理解、表达或跨章重复。先处理支撑不住的那一层，随后用[全章场景精修](scene-revision.md)和[两遍审查](event-progression.md#交付前分两次审查)完成适用工作。不是每个批次都要修改所有层，更不要求每场都改。

章群阶段性结果按[支线收束](narrative-variation.md#支线阶段性收束与交错兑现)辨认：办完一项事或回答一个具体问题，可以保留更大的未解部分。开新副本前看旧段实际兑现了什么，不能用角色宣布“先放着”代替答案。

## 人物纵向、缺失场景与双轨记录

全书深修或人物连续性任务先建立有出处的关键节点索引：同一人物的初始表现、关系建立/变化、重大选择与情绪反应、近期可比表达。全量范围仍须实际通读；索引仅用于定位，不要求在正式写作前穷尽全书每句对白。跨章问题可以提前回查或在随后单元验证，记录实际覆盖和未决点。

沿用现有记录增设必要字段即可，避免五套重复账本：

| 记录面 | 最小有效证据 |
|---|---|
| 人物纵向 | 人物、关系/时点、原文证据、表达与欲望的变化、变化依据或待核；同时记反例和优秀场景 |
| 缺失场景 | 触发点、此前积累与知情、原文实际反应及后文、缺口/留白判断、改法与状态 |
| 双轨因果 | 重要选择及现实后果；情感与关系余波及后续可比相处；下游位置、已验证/待验证 |
| 场景与章群 | 原场景功能、阅读损失、保护项、实际补写/删并/重排、连读结果 |

无需每人每章一条；记录只针对有意义的变化、缺口和风险。普通生活不建立强制兑现事项。只审读时给证据和候选，授权重构则写回实际稿。若上下文不足，保存可靠版本、覆盖与停点，明确下一实际任务；已有全量授权则尽量连续完成多个完整叙事单元，不逐场请求确认，不以抽样扩大已完成范围。

## 修改规模与授权分别判断

需要区分处理规模时，可在已有批次记录中用以下标记，不另建逐章表：

| 标记 | 实际处理 |
|---|---|
| L0 | 完整审读后保留原文；完成仍须满足本轮适用的复核要求 |
| L1 | 局部句段修复 |
| L2 | 完整场景、对手戏、动作或心理过程重修；在现有章界内补足有依据的缺失场景 |
| L3 | 合并、拆分、重排章节或结构重写 |

这些标记不表示质量高低、授权等级或完成状态。一句台词也可能改变责任、承诺、关系或知情，整场重修也可能保持全部既定事实；均须另查本次权限。L3须有章群证据及已有结构授权，不能累积细碎L1改动变相实施。只许对白自然化时，L2也仅限对白及必要接口，不开放一般场景重写。

## 问题要能从发现追到复读

沿用一处记录，按需要保留：具体位置与原文依据、损害的阅读体验、最小处理、触及的事实或后文、当前状态。状态分清“待处理”“已改待复读”“已复读仍有问题”“本轮范围内已处理”“超出本轮范围”；不要用其余项通过抵消未解决项。

轻微文字与局部承接按现有授权直接修；重大因果的结构改法按既有决定处理或提出具体分歧，不借“自动审查”自行改大纲、死亡、责任和恋爱进度。问题暂不能解决时明确欠什么，不把它换个名字记为完成。

## 撤回改动与停止机械化

使用现有版本或修前依据，使修改可逐项比较和撤回；不因已经花过时间就默认新稿更好。按[收益与损失判断](scene-revision.md#修改收益与原文保护)连读后，若风格修改收益仍不明确，或文字虽顺却削薄情绪、改了动机、丢掉递进，撤回相应改动。已核实的错字、标点、动作或知情冲突修复不随之撤销；作者有意的口语、粗粝和节奏不作错漏。若原稿本就有问题而新修法又不成立，保留待办及证据，不能把恢复旧问题记为解决。

发现连续套用同一种删句法、人物声音趋同、场景缩短而情绪变薄，或反复引入动作和事实错误时，先停止向下一批扩展，复查最近受影响的完整叙事单元。无需等多个征象凑齐，也不因正常重复或单章短小就自动停工。辨清问题来自个别改动还是共同标准，只撤回有问题的改动或调整无效标准，保留已验证的修复；当前批完成必要返查、说明未决项与可靠版本后，依已有授权继续。停止扩批不等于要求作者逐章重新批准。

事实返查追踪本次改动波及的事件真相、读者在此处掌握的信息、各人物在当时所知与所信，以及亲历、转述、回溯或失忆如何影响记忆。核对身体、能力、物品、时间和事件后果，尤其留意重复起身或拿取、伤手同时占用、能力限制消失和已处理事项重开。遇到疑点先查正文与已定规则，按实际信息差保留人物的误判与隐瞒。事实核对后另读完整交流、生活质感与情绪余波。

## 完成状态必须对应稿件与标准

记录所读版本，可用实际修订号、提交号或文件hash；同时注明本轮要求和覆盖证据。正文后来又变，受影响的旧审查标为待复核；标准改变，即使hash未变，也不能自动沿用上轮完成。hash只证明文件是否一致，不能证明文字合格。

明确区分：

- **本轮文学复验通过**：对最终实际稿完整读章，逐场处理适用问题，先复读文学收益，再复读完整章群的因果与节奏。原样保留的场景也有具体理由。
- **已审待修或待核**：记下仍需处理的问题、原文依据和待查来源。局部句段、差异或交界检查按实际覆盖记录。
- **已改待复验**：正文已实际修改，记下受影响的场景及还要复读的邻章。已经复读但仍有问题时，记录具体返工点。
- **未处理**：后续仍待进入的章节或场景，从实际停点续办。

全书或长章群终验须另做连续阅读，追踪人物声口、创伤余波、关系推进、身体恢复与能力状态、季节和时序，以及多章是否反复执行同一种调查、救援或收尾。章级结论累积后仍须过这一关。对重要人物纵向核对初始性格、重大关系节点及后期表达；对关键事件反向检查原本没有被写出的反应，不能只追已有改动。全书终验必须基于最终累计正文的完整连续阅读，定向节点复核仅记录为定向。跨章复读产生的返工，更新受影响的章节状态和复验依据。

增量续办只跳过版本、标准、覆盖三者都仍适用的部分。改动早期状态时，沿相关人物、事件和物品检查下游；只复核受影响处，不为证明认真反复扫全库。中断后从实际停点接，不恢复过期缓存覆盖新稿。

默认单主笔完成；只有已有委派授权才采用多agent。即使委派，仍需明确每个范围的输入版本、相邻场景、知识边界、编辑权限及整合责任，不能把孤立章纲的并行产物直接算作全书连续性通过。

## 交付与后续资料

按作品及本轮约定核对章节齐全、插章顺序、原文件名及 Markdown 图片引用。图片实体缺失时保留引用并记录缺项。程序比对未修改文件与基线是否一致，排除混入旧批次底本。综合精修交付完整累计正文、实际修改章节、逐章与章群报告、真实 Diff；保留章也列入覆盖。将开工时的累计基线与最终稿实际比对，核对差异可还原修改结果。交付载体沿用作品约定。若同时要求累计差异与本轮增量，分别以作者基线、本轮开工底稿为起点，验证各差异应用后都能还原对应交付稿。

交付说明完整读审范围、实际改稿范围、仅核承接范围和待办。逐章与章群报告可合在已有记录中。用场景位置、具体的阅读判断、修复或保留理由与仍待处理的问题支持结论。自审与作者终审分别记录，按最新工作稿维护实际接续，仅同步确有变化的事实与状态。

程序可以检查文件、版本、范围与链接；文学效果须看完整场景和作者反馈。新增案例先标原创示意或外部参照，真实作者认可才记录认可范围，不把编写规则本身当作已完成独立效果实验。
