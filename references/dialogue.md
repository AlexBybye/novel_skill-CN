# 人物对话生成与独立审查

用于含连续互动的创作、场景重写及对话系统诊断。不是固定台词、情绪流程或自然度评分器。简单句子润色仍守原文契约；只修 skill 时不顺手试改作者正文。具体人物与章次留在作品档案，不进入通用技能。

## 先分开两种需要

只修对白时，保留作者满意的其他叙述与情节，不扩大到整体节奏回修。先分开主笔要让读者理解的信息与人物此刻想从眼前人那里得到的东西。前者决定信息何时可见，后者决定为何开口、接哪部分和何时不再说。解释与推理可以直接成为交流内容：它们若影响判断、说服、利益或关系，就不只是补课；不因台词长、问答多或明确说心理便判失真。

先从授权与当前版本保留事件结果、人物动机、关系阶段、知情和误信、证据原话、揭示顺序、媒介及能力限制。它们是写作边界，不是分配给角色轮流念出的台词。权威人物可以辩解、偏私或说谎；旁白与后果仍须分清事实和他的说法。语言自主不赋予角色改写已定结果的权限。

需要读者获得的信息，可以由现有行动、可见材料、视角内观察、必要概述或人物有理由说出的话承载。选择符合本作视角和节奏的方式，不强制全改成“展示”。不能把双方早已知道的背景伪装成新问答；旧事若用于追责、试探、索取承认或亲近则可重提。也不能为减对白把角色尚不知道的谜底搬进限知旁白。

## 信息分层与认知路径

用于一场兼有背景说明、立场冲突或多个新概念，读者却不清楚正在解决什么的谈话。句子通顺、资料完整和人物各有动机，都不能证明信息可以被顺着理解。先找到本场双方实际在谈的主问题；分歧、岔话和私人牵挂仍可改变进程，不把它做成角色逐项宣读的议程。

- **从已知走向新知。** 对照前文，区分读者已见、角色已知与本场首次说明。新地点、规则或派别先与可辨认的人、事情或已有概念建立关系，再继续解释它的由来或目标；必要时先用普通说法再给专名。不要拿另一个尚未落地的名词解释前一个，也不为降名词密度删掉必要的因果。已建立的称呼不必逢场重新定义。
- **一层回答接住一层问题。** 问入口如何使用，不能未经交代就改答整个世界的起源；要转层，须让人明白两者的关系，或在插话后回到尚未回答的问题。可用长答、短答、概述或有内容的反应承接，不规定每段说明后必须追问，更不能把一个连续念头切成逐格索取答案。
- **区分回答与回避。** 先核对这次到底回答了什么，未答的是不知道、无权说、不愿说，还是根本没听进。连续用“以后再谈”“今天交代不全”换话题，会把悬念变成扣信息。保留有动机的关键拒答，给读者可辨的拒答状态及对方如何继续；不强制角色坦白真实动机、不新增权限制度或后台事实替回避找借口。作者尚未设计答案，也不能临时编定。
- **给指代足够的锚点。** 人群、地点或话题切换后，“他／他们／那边／这里”若有多个可选对象，补名字、身份或最短必要旧事。连续读时本来清楚的省略照留，不把每个代词都改成全名，也不把上一章重新讲一遍。
- **冲突和旁线不能被说明盖掉。** 隐瞒被指出、信任受损或请求被拒后，检查后续说法和选择有没有承受这一变化；不只是质问一句便让另一人继续讲设定。生活声响、亲友相处与内心可进入停顿或转层，但核心解释尚未落稳时，避免不断另开一条同样要理解的线。不能为清楚而删光闲笔，也不要求冲突当场和解。
- **多人从各自关切参与。** 某人可以追究伤害、某人更急于弄清自己处境，但这是本场的立场，不是永久分配“提问者／讲解者／风险提醒者”。插话须接着本人实际听到和在意的部分；不要轮流点名，或让同伴只替读者追下一个术语。

修后沿完整交流追一遍：最初想弄清什么，读到哪句话得到哪部分答案，新问题为何在这里出现，哪些问题被明确留下，最后如何据此行动。允许混乱、误听、不可靠讲述和未解悬念，但读者应能辨认混乱属于谁；不能把理解内容、相信说法和情绪接受当成同一步。此项与人物开口理由、机械应答检查同时执行，不以清晰取代人物性格。

## 动笔前：让每人有自己的开口理由

实际读取本场各人的语言行为、关系与阶段知情，沿用个人卡，不把总表标签当人。语言行为档案的最小记录见[两层模板](character-templates.md#语言行为档案沿用个人卡)。缺少某类情境的证据可留未定，本场在已有授权内作执行选择，不靠虚构往事填表。

以下问题用于遇到具体困难时判断，不要求每场逐项填卡、给每人安排隐藏欲望或另交准备报告：

- **为什么现在对这个人说？** 想让他留下、承认一件事、给自己台阶、接受交换，或只是想一起闲聊。确实在问事实时，仍要知道事实对本人有什么用。
- **本人带着什么预设？** 以为对方会偏向自己、害怕被看穿、觉得自己已经解释够了，或尚未意识到对方生气。不能强制每人都有秘密和潜台词。
- **愿意说到哪里，怕付什么代价？** 这决定直说、敷衍、解释过头、反问、玩笑、拒答或正常回答的可能性，不预排每轮必须怎样反应。
- **为何换成另一个对象就会不同？** 同样的沉默，面对控制自己的人可能在拒绝交代，面对在意的人可能是不敢失去。句长相同不代表行为相同；具体原因须有档案和场景依据。

若这份准备只剩“甲负责问，乙负责解释，丙提醒风险”，先重做。允许职业分工存在，但不能让它代替各人的立场。没有分歧的日常也可成立，不为填“冲突”栏造敌意。

## 成文：一口话与整场相处

先写此人这会儿对眼前人实际想说到的地方：请求可能连着借口、承诺，抱怨可能带出旧事，说着又想起一个补充。不要先按信息点一条一句切开，再让别人逐条提问。这里的“一轮”不要求语法完整或一次讲清；熟人能接的半句、自然省略和未说完的话照留。长短随此人的念头、压力与对方反应变化，不设混合比例，也不为纠正短句强迫寡言者多话。短答可以接受、敷衍、拒绝、打断或承受冲击；若整场只有准确填空，需重看说话为何发生，不只是延长句子。

区别人，先看他怎么组织念头、称呼眼前人、愿意给谁解释到哪里、把注意留给什么、怎样顾着或不顾着对方。句法随对象和处境而变，不给每人永久分配句长、口头禅或一种情绪。普通话允许平淡，必要指令可以清楚，不要求句句机智或暗藏意思。

下一轮从本人实际听进、在意或回避的部分接下去。有人先抓住一句冒犯，稍后才补答原问题；有人说着修正自己的判断，有人因走神漏接一句。让这种偏移有可追到的注意、情绪或关系依据，不把所有回应修成精确问答，也不统一增加错接、结巴、跑题和骂人来表演自然。事实已听懂，并不等于愿望得到满足。

把动作、神态、内心与环境放在交谈发生的同一时间里：人在做什么，能否边做边说，什么时候停手、转向、等对方。活动与身体状态可跨过几轮，也可连续几句只有台词；不每句重新安排抬眼、握紧、放下。普通生活动作可以只让人活在此处，不必件件推进情节或象征情绪；但不能用这些动作给原封不动的问答清单作自然度证明。沉默也不自动等于含蓄、拒绝或羞耻。

长内心可以占很多篇幅，却不表示现场别人等了同样长时间；回到交谈时分清他实际看见了什么、听见了什么，不能让他回答对方没说出口的内容。一次迟疑、咳嗽或手边事务可能改变回应，也可能只是叙述停留，按实际过程判断，不预设每轮都要动作产生转折。

需要具体校准时，读[真实对白中的连续过程](dialogue-in-scene.md)的短场景锚点，兼看前后轮与动作位置。例子供理解选择，不移植台词、桥段或反应顺序；本来成立的短句与平常问答不必改。

交流可以止于事实核实，也可以止于某人不愿听、话说重了、事务打断或暂时一起做事。重要关系场要让距离、信任、态度、期待或权力的变化可感，或让既有裂缝与代价具体显露；在已定关系进程内完成，不为达标新增决裂、原谅或恋爱。事实明白、情绪缓和和关系修复不必同时发生。既定的和解也不能为了留下余波被撤销。

### 机械顶嘴与机械应答

审查整场以及可比的不同关系场，不能只修少数逻辑失接。人物各有目的、冲突有依据、回应接得上或结尾未和解，都不足以证明交流自然；每句能单独解释，也可能连起来全靠接招。

以下是需要回看完整过程的信号，不是禁用句式：

- 随口感叹、抱怨或关心总被当作待驳的观点；抓住上一句的一个词反问，临时制造一个本无须核实的问题。
- 先否认对方没有要求的意思，再澄清自己；已经认同，又补一句保住输赢；总由一方用机灵话或冷话拿走最后一句。
- 本可接着说的念头被拆成逐问逐答，听者逐格索取原因，或反复换个问法让对方确认谨慎、理解与正确立场。
- 不同人物与关系都靠同样的顶嘴表现亲近、靠抠措辞表现冷淡、靠连续提醒表现关心。更换语气词、拉长句子或添加动作并未改变这种往返。

判断这轮话是否成立，要看争的是人物真正在意的事，还是作者刚安排的措辞漏洞；回答怎样影响随后所说、所做，还是只为对方递出下一句。普通回应无需产生新变化，随口说的话也不必逐句回答。修整时沿本人尚未说完的念头与正在做的事重组连续互动，允许正常回答、顺势认同、默契省略、不接无须接的话，或把心思留在别处；不要逐个同义替换反问，也不把一套顶嘴统一换成沉默、笑或长篇解释。

真实争执、追责、必要确认、有依据的嘴硬，以及作者有意的拌嘴喜剧可以保留。重复“别挂—没挂”若在确认对方仍在，与为凑来回重问已知事实不同；重读一本已经读过的书，也不天然需要先争论读到哪里。按当场内容判断，不设删减比例，不要求人人温顺、坦白或不再幽默。

## 话如何被场内人听见和使用

问句可能在索取事实，也可能要态度、承认、让步或服从；答对字面，不等于满足本次开口的要求。讲旧事或说明来意时，也看本人希望眼前人怎样看自己、接下去怎样相处；坦率说明和普通闲聊同样成立，不预设人人另有隐藏目的。

同一句话可以对一个人说、让另一些人听。多人场跟着谁的插话改变了谁的资格、信任或下一步写，不按点名轮流交付观点；没发言的人也可能是正在争取的听众。称呼、礼貌、反话随当场关系与受话人变化，不当永久人设符号。别人可能顺着字面接成有利于自己的意思，作者须分清可见效果与尚无证据的故意曲解。

遇到此类具体困难，再读[场内听众与话语作用](dialogue-audience.md)的真实场景；句子形成及动作时间则选[真实对白中的连续过程](dialogue-in-scene.md)。两份参考各解不同问题，不是每场必读或逐项验收表。

## 第二次审查：完整对话与人物行为

先完成[第一次情节审查](event-progression.md#交付前分两次审查)，再以完整对手戏为单位重读台词、行动、内心和停止交谈的方式，先定位实际读感损失，再用下列判据追查原因；判据不要求新增冲突、动作、潜台词或完美沟通。不能只审摘出的台词，也不能因逻辑准确便把第二次审查勾完。每章检查下列七项，跨章同一场还要连读；独立片段只对实际覆盖的范围负责。

| 验收项 | 看什么证据；失败时怎么处理 |
|---|---|
| 人物声音可辨认 | 遮去姓名看完整来回中的关注、组织话的方式和待人差别，再看同一人对不同对象的变化。普通“嗯”“饭还热着”无需单独可猜身份；若整场可任意换名，回到语言行为与关系重做。 |
| 没有问答清单与机械接招 | 连续回应是否只在交付下一条事实，或抓词反问、逐句纠正、总争最后一句；上一句带来的受挫、顾虑或愿望有没有进入下一句。按[机械顶嘴与机械应答](#机械顶嘴与机械应答)检查整场与可比关系场，不以逻辑成立或有动机豁免。真正的审讯、查证、普通短答与有意拌嘴不因形式相似判错。 |
| 重要对话有关系作用 | 指出哪一句或哪个行动改变或暴露了距离、信任、态度、权力及其代价；仅核实事实不能替代本应发生的关系转折。普通手续和稳定日常可不适用，不为过关制造新关系事件。 |
| 没有机械动作补丁 | 拿掉动作标签后，问题是否仍是相同的清单问答。动作和沉默为何在这里成立，有没有把每句话译成一个身体信号；不能靠多添动作判通过。 |
| 人物不替作者解释 | 台词为何说给眼前人听，而非只供读者补课。信息密集场另按[认知路径](#信息分层与认知路径)核对主问题、新概念锚点、回答与拒答及插话回接；不以事实齐全或人物有动机代替。必要背景可走合适的叙事通路；共同已知内容若在施压或亲近，保留其用处，不机械删去。 |
| 没有整齐的情绪解决 | 是否默认按质问、解释、理解、道歉、共情、总结一次完成；结尾是否服从既定人物关系和本场需要。作者已经确定的和解仍应保留，不强制每场留怨。 |
| 事实与关系未被篡改 | 对照写前边界及相邻实际稿：事实、动机、伏笔、知识范围、表达媒介、关系阶段和后续承接有没有被改掉。不能用新增敌意、告白或提前揭密换取戏剧性。 |

记录每项为“通过／待修／不适用”，随实际场景留简短引句或位置及判断；重复问题可共用证据，不必七段长报告。没有对白可标第二遍“不适用”，并检查人物行为，不假报七项通过。任一适用项仍待修时，不报本章对白达标；在当前授权内改整场，再复读受影响交流。无法在既定因果内解决的矛盾明确留下，不用总分或其余项通过抵消。

第二遍不是把人物话里的不准确都纠正成正确答案。区分角色有理由说错与作者写错；第七项检查作者边界，不要求人物自己解释边界。表达修整后仅针对受影响的事实与承接复核，发现越界撤回越界改动，不把人物重新修成准确传话器。

程序可标出高频句式、连续问答、重复指令，输出候选位置即可，不能凭次数判错、自动替换、打自然度分数或代替编辑判断。同一句“我不知道”可能有不同作用。机制文件、格式和测试通过均不证明文学效果，效果要看真实完整场景与作者反馈。

## 系统重构如何验证与推广

作者要求全书重构时，先保存现稿并确认当前版本及本轮授权。按作品指定的典型关系选少量试验场，分别留原稿、候选稿、不可变边界及两次审查证据；未获正文改写授权时仅准备验证，不暗写试验稿。不要用本节扩大“只修 skill”的请求。

比较改写是否从人物自身需要发生、怎样接话和停止，而非比较动作数量、短答减少多少或冲突是否更大。不同关系均有成立的完整稿后，再按作者指定的关系重要性与问题严重程度分批回修；原已自然的日常和必要指令尽量保留。冻结续写、试验章次、推广批准条件与优先级属于作品当前指令，不设成所有作品的永久禁写规则。不得把未做的试验、编写者自查或旧的不完整评测写成已经验证机制有效。
