# 人物底层卡与场景呈现卡

用于作者要求固定人物骨架、现有人物扁平，或把已讨论设计落实成场景时。与[人物设计](character-design.md)配合使用：底层卡长期维护，场景卡只取此时有关的内容。沿用人物自己的Markdown，不另外制造竞争档案。

## 底层卡：这个人为什么这样做

重要人物按下面八个维度组织；写有关联的解释，不只填标签。缺证据的新增设计标为候选，未定内容可留未定，不为填满卡片编造创伤、重大履历或结局。

| 维度 | 要回答的问题 |
|---|---|
| 第一印象 | 谁初次见他、在什么场合，会怎么判断？此判断可能准确，也可能只见到一面。 |
| 外貌识别点 | 哪两三处轮廓、衣着处理或表情变化能被记住？区分长期特征、年龄阶段与当场状态。 |
| 动态习惯 | 做事、听话、思考或紧张时怎样动？适用条件是什么？不是每次都触发。 |
| 社交模式 | 对有关的几类人，主动程度、索取、照顾、边界和声口如何不同？ |
| 欲望 | 想过什么日子、此阶段最想得到什么？生活的小愿望不能全被主线覆盖。 |
| 恐惧与底线 | 怕哪种后果，愿意承受什么，不肯付什么代价？没有深层恐惧也可写普通顾虑。 |
| 自我辩解 | 有哪句话会保护他的自我评价，使他不愿承认自己的另一种动机？可以暂无，不强求人人自欺。 |
| 性格矛盾 | 两种需求或原则在哪种选择中冲突，谁因此受益、受累？不要求与第一印象完全相反。 |

用因果串起有关项：**想得到什么 → 顾虑什么 → 怎样解释自己的做法 → 因此作什么选择 → 留下什么后果**。这是一条设计路径，不是人格定律；人也会因兴趣、好奇、责任和习惯行动。不能把所有行为都追溯为恐惧或丧失。

### 三层结构：可选的分析工具

- **表层表现**：他人平时能见到的真实行为，不必是伪装。
- **受压时的防御**：哪些条件使他辩解、回避、求助、攻击或改变策略；写具体触发与限度，不作心理诊断。
- **核心需要或原则**：长期愿望、不可轻易让出的价值。可以与表层一致，不必藏着阴暗秘密或等待崩溃。

三层能解释人物时再用；稳定坦率的人不必另造隐藏人格。自我辩解不一定是有意撒谎，也不等于角色知道作者的未来谜底。

### 优点的代价与独立缺点

可以沿“强项 → 过度使用或错用的条件 → 别人承受的后果 → 自己如何补救”展开。比如会规划的人，在他人需要自主决定时仍替人安排，会损害信任。也要保留独立缺点，不能让所有坏处都变成美德太多，不能用好意抵消责任。缺点的代价由实际情节建立，尚未发生时标为预演。

### 外貌卡：被谁怎样记住

按需组织为“远看／近看／最易记住／动起来／与第一印象的关系”，从已有外貌中选少量细节。普通面孔也能通过姿态、衣着选择和关系中的表情变化被认出。异常点、疤痕、长相与性格反差都是可选手段，不是填卡义务；不能为了辨识度加需要重大履历解释的伤残。旁观者的审美或误解不当作客观性格证据。

### 辨识锚点与变化轨迹

动作、语言习惯、物品、核心矛盾可选其中真正适合的人物锚点，不必人人凑齐三件。写明动作的触发和频率；身体习惯不是可靠测谎或读心证据，角色也不会无由知晓他人的习惯。标志物品不自动成为伏笔或异能道具。方言按[地域与说话对象](character-design.md#方言地域与说话对象)处理。

变化轨迹记录：**起初相信什么／当前被什么经历动摇／之后可能修正什么／哪些东西仍坚持**。已经发生的变化附章节证据；未来终点标为候选，可以成长、倒退、坚持或留下矛盾，不为卡片擅自确定原谅、死亡、背叛或牺牲。

## 首次直接登场：建立人物形象

人物本人首次直接进入实际场景时，是外貌与衣着介绍的执行点：动笔前核对此前是否已经直接登场，就在邻近行动中给读者能辨认的形象，不把全部外貌拖到相处数章以后。主要人物兼有轮廓或面部识别点、衣着处理和动态；有个体行动的短场配角也给简短可见特征，篇幅依叙事分量。作者明确的留白、视角遮挡或身份隐匿安排优先，不能为了介绍提前揭底。

**间接出现不触发介绍。** 仅被提及、语音、照片、新闻、转述、回忆中的简略提及等，保留原有描述，不强加外貌和衣着，不提前填完人物形象，也不能为满足模板让本人额外登场。待本人首次直接入场时再介绍。改已有章节时，原有照片细节可以保留；本规则不要求删去已有信息，也不授权扩写间接出现。作者明确要求描写照片或回忆时，按该次具体授权处理，不把它升级为所有照片都要补外貌。

介绍须个性化：考虑此人当天为何这样穿、视角此时看得到哪一处、哪种姿态最易记住。不同人物可分别落在衣服的松紧与磨损、整理程度、颜色选择、脸部线条、身形和做事动作，不轮流复制“黑发、冷眸、挺鼻、薄唇”，也不全靠反差。不要报身高体重表，不用一段外貌解释全部性格，不为区分强添伤疤或重大履历。

视角人物自己也在首次登场行动中建立可见形象，可以由衣料、姿态和同场人的自然相对关系呈现，不必安排照镜子。服装属于当前场次，脸与身体属于对应年龄阶段；直接出场时也要分别维护世界和年龄，不能把后来的灰发、体形或装束倒填前史。重复登场承接已有特征，以当场变化补充，不重新整套介绍。

改已有章节时，先列实际首次直接登场位置和已有描写，沿用原动作、人物意图和知识边界，在相应段落补缺；保留修订前版本，新五官与衣着记录实际所在章节及审核状态。不是每个出场都再填一次卡，衣着也不自动成为伏笔。

## 后续衣着复现：按作品约定控制频率

作者给出衣着复现概率时，严格沿用其值和事件范围。没有作品约定时不擅自加固定百分比。本工作流可以支持“本人首次直接登场介绍外貌衣着；后续每位人物每个新事件50%概率触发一次衣着描写”。具体概率是作品约定，通用skill不把50%强施给其他作者。

概率针对可选的衣着复现，不针对首次直接登场介绍，也不触发照片、语音或转述的补写。先定位稳定人物ID和事件ID，同一连续行动过程跨段、跨章、人物离开后返回，都沿用同一对记录，不能为了再次抽取拆事件。宏观事件已有子事件划分时按其真实行动单元标识执行，不用讨论日期或章号替代。拆分或合并后留下事件对应，已经抽过的连续单元不因此重抽。

在该人物首次直接进入此事件、且尚未有本事件衣着介绍时，用一次随机抽取判断，例如均匀随机值 `u ∈ [0,1)`，作品概率为p时以 `u < p` 触发；记录人物、事件、概率、抽样值、结果和状态。未触发也留记录。不是每两次强写一次，不为凑比例重抽，不凭“灵感”改抽样结果。检查旧记录必须先于抽取，改稿与跨轮续写沿用结果。

触发后结合当时可见的衣着变化、穿衣选择与动作写一小处，不重新介绍整套外貌；有观察条件时实际写出并记录位置，没有条件则在本事件首次可观察处落实，不能借此增加视角外信息。已写后标记已使用，同事件不再触发。作者另有明确要求以最新指示为准，记录覆盖理由。

首次介绍已包含衣着，或同事件已有明确衣着描写时，记录为已使用，不额外随机补段。衣物影响行动、确实换装或制服识别等必要事实照情节呈现，不靠随机省略，也不算额外触发装饰性介绍。服装要区分人物、世界、场次、天气与动作，未写的装束仍是计划；作者接受正文后再同步实际衣着状态。

## 场景卡：读者怎样认识这个人

底层设计不能原样倾倒进正文。写作或预演前，用这张短卡选择本场真正要发生的互动；讨论与预演仍不自动授权正文创作。

```markdown
场景时点、视角与关系阶段：
人物此时已知／误信／未知：
本场各自想得到什么，愿意付什么：
两人此刻不能同时满足的要求：
是否本人首次直接登场；间接出现则沿用原有描述：
本场适用外貌、衣着与辨识细节：
作品若规定衣着概率：人物/事件ID、既有抽样结果、是否已使用：
此场适用的性格侧面或声音：
触发 → 人物选择或行动 → 对方回应／实际后果：
对方拒绝或证据变化后，他怎样调整：
结束时改变与仍未解决的部分：
设计／正文事实的状态与来源：
```

让旁人承受人物的性格：有的人多安排一步，旁人少一次选择；有人讲求准确，可能让急着被安慰的人更孤单。受益、被逗乐、被照顾同样是后果，不只通过争吵表现人物。明确内心和必要旁白仍可使用，不能把“通过行为呈现”变成全面禁止说明或强行添加动作。

同一习惯不反复无条件表演。谨慎不等于每次重查已确认事实，嘴硬不等于每场都否认关心；重查、复沓或沉默有当下风险和关系理由时可以保留。动作不自动解释成唯一心理，视角人物可以误判。整场不必完成一条性格展示流程，也允许普通快乐和留白。

## 应用到已有资料

先核对正文依据与关系阶段，再把已有设计归并成因果链；沿用有用的外貌、生活偏好和声音，不另写一套相冲突的人设。优先修复本轮指出的空白和同质化。底层卡解释重复内容时用链接或归并替代堆叠；旧候选被修正就标明去向。作者新确认的习惯与旧章节已出现的动作分别注明来源，不把本次解释追写成早先角色已经知道的事实。
