# 转场与承接

用于时间、地点、视角或话题切换后读者迷路、人物状态归零、上一章的落点被下一章绕开的情况。先读前场末尾和后场开头，必要时读完整相连场景；不是所有“第二天”、空行或硬切都需要修。

## 先判断断在哪里

| 断口 | 先处理什么 | 避免的补丁 |
|---|---|---|
| 不清楚现在是谁、何时、何地 | 补最短必要定位，区分故事时间、叙述时间和跨线先后 | 为显得巧妙反而藏掉定位，或重讲整段前情 |
| 目标、情绪、关系或身体突然变了 | 回查前场实际状态，找到已有的触发与中间一步；必要时呈现或概述 | 加一个时间词便让伤势、恐惧和旧争执消失 |
| 地点到了，因果却没到 | 看为什么来、在途中或跳过的时间里有什么必要变化 | 把一路登记、清点、候车全补回去 |
| 章尾许下期待，下章却另起一套 | 明确读者在等谁怎样回应或会发生什么；后场要承受其后果，或有可辨的暂缓理由 | 重播同一条线索、先总结一遍，再用无关新危险推迟 |
| 感官或物象很顺，事实却错接 | 查时空、物品归属、获知途径与视角 | 相同物象自动等于同一时刻、隔界感应或信息互通 |

修前在当前准备中想清：前场有什么仍未放下，后场从什么状态进入，中间哪些事可略写、哪些因果不能跳。只记与实际断口有关的内容，不给每次切场新增六项填表任务。

## 选择合适的连接

时间定位、人物目标、未完的活动、共同事件、声音、物件、感官或有意硬切都可用。需要桥梁时，优先已有内容；不为“无痕”专造电话、来客、异常或一件象征物。回忆与梦境要让读者能分清进出边界，但不强制每段回忆都有触发物。

下一场可以安静、只是生活或继续承受上一场，不要求第一句必有新信息。上一场的余波也可以迟到或暂时退后；不能让每次危险都机械接喝水、每次私人冲突都立刻转任务，更不能让每个平静结尾被新的钩子取消。

作品明确要求物象切线时，沿其要求落实到前场结尾与后场开头，兼查[物象与时间](lived-scenes.md#意象切线也要核对时间与物品)。其他作品不强制使用同一种连接。

## 修后怎么读

去掉编辑说明，连读前场最后一段与后场第一段，再读受影响的完整过程。读者应能定位，人物带来的伤势、目标、关系和注意仍成立；桥接没有代替本应经历的反应，也没有把可概述的路程重新写成流程。不以转场词减少或连接方式变多判断进步。

只获局部修辞授权时不搬场、不改重大揭示；结构断口需要重排事件时，说明具体影响并沿用作者既有授权。章末审查仍由[章节两遍审查](event-progression.md#交付前分两次审查)负责，不另设第三套验收。
