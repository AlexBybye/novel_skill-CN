# 事件推进与章节自审

人物档案已有内容而正文仍显工具化，或工作对白、体感与支线牵连失效时，按需查[让人物活在场景里](lived-scenes.md)，从私人诉求进入选择与后果定位问题，不统一补怪癖。

用于整章、连续章节创作或重写，以及推进乏力的诊断。结合当前作品的风格与作者目标选用；不是“每章必有灾难、反转、信物”的公式，也不以字数、短句密度或钩子数量证明质量。平静、舒缓、余波和留白可以成立，需辨认其具体作用。若作者指出的不是单章乏力而是**跨章同构**，应先读[长篇叙事生态与跨章去模板化](narrative-variation.md)：本文件检查单章因果，不以“每章都必须推进”来修复整部小说。

## 写前：让设定变成人物必须处理的事

- **事件有可追溯的因果。** 梳理触发条件、人物依据、所做选择、直接结果与后续负担。规模来自影响和选择代价，不能只把普通任务换成更大的事故名称。隐藏原因可以暂不揭示，但可见后果应有因果支撑；区分作者知道、读者可推断与角色已有证据，不让角色提前说出谜底。
- **能力改变局面，也留下问题。** 按已确认的条件、对象、范围和代价安排使用；检查它解决了什么、还剩什么、谁须接着行动。多人协作应有各自不可替代的贡献，也保留普通人的判断和专业方法。不能临时削弱、失灵或新增副作用来强造危险，不能为“有代价”擅自增加未批准规则。能力不适用的作品跳过此项。
- **私人牵挂影响公共选择。** 有身份、资源和职责的人会怎样调配资源、判断线索、交接任务、承担风险？把私事放进这些选择及其后果，避免只在工作场景插入几句走神。外部压力可打断计划，但主动调查同样可以有张力；不要把“被动卷入”规定为唯一驱动力。
- **预先辨认本章存在的理由，不强制本章发生变化。** 可能是事实、关系、处境、选择或代价改变；也可能是一段有自身阅读价值的生活、承受与观察，人物和读者都没有获得新的线索。连续几章若只重复同一组失联、担忧、等待、核验，检查读者是否真的经历了不同内容，再决定保留、合并或重组；不是给每章添加一条信息或一次小反转。不可为了“有变化”藏住本来会问的问题、强造误会或临时生成危险。

## 成文：让变化有可感知的落点

**描写与停留。** 充实情节不只增加行动和信息。按作品当前反馈展开场内空间、环境、人物状态、动作过程、感官与生活细节，允许气氛、审美和相处本身占据叙述时间。作者指出文字过于干练或信息拥挤时，从首稿给读者经历场景的余地，不把所有段落压成关键对白、线索与结果；沿用[描写与闲笔调节信息密度](style.md#描写与闲笔调节信息密度)，不以新增旅游支线代替现有场景的展开。

**情绪与物件。** 优先从既有物件、身体经验、空间和动作中找承载。检查具体对象为何进入视角、人物怎样对待它、它随事件发生了什么意义变化；已有的一双筷子从准备吃饭变成无人使用，比连续添新信物更有力。不强迫所有情绪经过物件，直接心理与对白也可以充分成立；避免把象征意义再逐句解释给读者。

**日常与支线。** 它可以只呈现人物自己的生活、形成有效的气氛与阅读停留，也可能改变关系或选择。若段落可以在任何位置插入且毫无可感差别，应检查是否仅在填篇幅；但不以“不会推动主线”证明它无用。支线与主线的关联可以通过选择体现，也可以暂时没有显著交集，不必由旁白点题；不规定每一句、每场甚至每章都推进谜底或兼任伏笔。

**双线与镜像。** 转场可用物象、人物目标、声音、时间定位或硬切，选择适合本作的方式；作品明确规定物象递接时继续执行。开头仍明确必要的视角、世界和时间落点。选用物象时按[物象切线](lived-scenes.md#意象切线也要核对时间与物品)检查切换两侧。物品归属、时序及信息通路须成立，不强造同时性，不赋予物象额外异能。

**对白承接。** 逐轮核对对方实际说了什么、本人此刻想获得或避开什么、关系和压力为何支持这句回应。玩笑、追问、坦承未知、拒绝与沉默按场景变化；人物特色不能靠统一斗嘴或审问。沿用[对白承接与场景语气](style.md#对白承接与场景语气)，不虚设误会来凑对话。

**专业信息。** 按作品读者检查必要术语是否在情境中可懂，流程篇幅是否掩住人物的选择、冲突与后果。同一事实反复对表、签字或核记录时，依[专业信息与非专业读者](style.md#专业信息与非专业读者)审查整场，不仅替换几个词；保留能力条件和关键因果，具体重组遵守当前授权。

## 交付前：分两次审查

每章创作或重写先完成第一遍，再重新通读完整对手戏做第二遍；连续章节逐章记录，跨章交流连读。两遍可以由同一主笔先后完成，不默认委派，也不声称是独立评委。不得在一次综合润色中以信息完整抵消人物失真。在已有任务卡或自审记录中分别留下依据，不把检查表写进小说。

### 第一遍：情节逻辑、设定与伏笔

1. 说明本章的实际阅读内容与停留价值：若出现变化，指出是哪些行动或证据所致；若本章主要是日常、情绪余波、观察或尚未得到答案的过程，可以如实标为“无新的情节信息”。不能把只有作者知道的答案冒充读者获得的推进，也不能因“无变化”自动判不合格。
2. 对关键转折追问“为什么现在发生、为什么此人这样做、结果怎样迫使下一步”。缺少动机、条件或后果，先在已授权范围内修复，再润色句子；不能靠添加形容词和反应动作遮住结构缺口。必须改变重大情节才能成立时，提出具体分歧。
3. 核对时序、视角、地点、知情与误信、媒介、物品伤病、能力条件、专业行动及伏笔可见度。角色撒谎、说错或误判须与作者记录中的事实分清；不要求角色逐句解释正确答案来证明检查完成。
4. 检查章尾是否与这章实际经历相称：可留新问题、决定、代价、关系变化、情绪余波，也可平静结束或在行动中切走。反复用预告句、象征总结或新危险替每章强行制造悬念时，应回查相邻章；既定真正的信息反转不因“钩子太多”就删除。
5. 连续章节比较各章的**阅读体验与叙事职责**，不按“每章一条新信息”分工。允许纯日常、同一事件的延长承受、连续高压或整章停滞；只把同一轮无新体验的等待、核验切碎时，才考虑合并或重组。篇幅和是否强钩子均不作为通过标准；连续章群的重复模式另按[跨章观察](narrative-variation.md)诊断。

完成本遍后保留不可改事实与关系边界，单独记通过项及未解决问题；结构尚有问题先修结构，不能靠润色遮住。

### 第二遍：对话与人物行为

按[对话七项验收](dialogue.md#第二次审查完整对话与人物行为)逐项判断，通读完整交流及相邻承接，单独记录引句或位置、关系作用、实际修复与残留。第一遍通过、读过人物卡、增加动作或闲话都不能作为本遍通过的证据。

同时核对关键情绪的分量、日常质感、描写停留与[体验连续性](lived-scenes.md#体验连续性复核)，再做适用的[内置表达审阅](novel-humanizer.md)。检查人物行为是否与其语言、关系及眼前需要相连；普通生活和必要描写可独立成立，不为每句补情节用途，也不以词数、动作数或删尽闲笔证明充分。

第二遍修改如碰到第一遍锁定的事实、知识或关系边界，撤回越界改法或明确列出矛盾，再复核受影响的承接。不要为了“更自然”更改动机、关系进度或伏笔，也不要为了“更准确”把所有人改成解释者。没有对白时标明对白项不适用，仍查人物行为。

两遍各区分“已检查并修复／仍有问题／不适用”，不合成笼统的自审通过，不宣称自审能保证文学质量。保持[草稿与已接受正文的状态边界](memory.md#章节审核完成后的归档)，交付时遇到并行修改按当前文件复核，不能用旧缓存覆盖。
