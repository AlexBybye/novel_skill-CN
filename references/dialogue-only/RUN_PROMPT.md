# 对其他智能体的执行指令：以人工精修效果为目标

请将本次任务明确识别为**《没有人应该出生》全书人物对白的人工编辑式自然化**，而非“扫描 AI 味并批量添加口语特征”。我已经对前期部分正文做过人工校对；我要的是让你参考**我明确认可的现行对白**，学习我判断哪句话顺、不顺，以及什么时候应该保留原样，从而减少全书后续章节必须由我逐句亲自改的负担。

严格遵照 `novel-dialogue-humanize-zh/SKILL.md`，**首先读取 `references/editorial-calibration.md`**，然后按 `references/batch-protocol.md` 完成全量任务。另一份 `novel-coauthor-zh 2.0.0` 是背景 Skill，但不得使用它的结构性改写功能来扩张本轮权限。

**目标优先级**：①这句话在完整上下文里，是不是自然、通顺的现代中文对白；②是不是这个人物在此时此地、面对这个人会说的话；③下一轮话有没有正常接上对方真正在说的内容；④改动是否必要、是否比保留原文更好；⑤是否严格保持原情节、态度、信息、关系与文风。不是“是否每句有潜台词”“是否每句改变场面”。

请纠正以下错误理解：

- 不要宣称真人对话必须有固定比例的废话、口误、语气词或半截句。**不用向正文强行补这些东西。**
- 不要把“我没说 A，我说 B”、三项并列、短问句、称呼后质问等写进必改黑名单。它们是否自然必须根据前后完整话轮判断。
- 不要认为情绪重头戏就一定要表达混乱，日常场景就必然更自然。真实的人有时会简短直接，有时会清楚地讲一长段，也可能语无伦次；必须有本场依据。
- 不要把过于整齐的核对问答换成另一套整齐的顶嘴、沉默、反问、摸杯沿或“我不是……只是……”结构。
- 不要按先前模型的章节评语，预设某一章某一句必须怎么改。**只以我提供的最新正文和确证的作者样本为准。**

**执行方法**：先用现行稿中由我明确认可的对白和可获得的“AI 版→我人工校对版”成对片段建立少量校准示例；对于确实没有成对稿的场景只作谨慎比较，不杜撰样本。试运行 6～12 段有上下文的不同场景，同时展示原文和一个最佳精修版本，允许建议原样保留；记录选择依据。若我已经提供足够认可和拒绝样例，则直接沿用，无需再次询问或阻断任务。校准后按相连章节逐批读审、修订、回读、核对全章，不为制造改动量重写对白。每批抽查普通、高情绪、修改多、原样保留的场景；模型自评不能代替我的认可。

**修改权限**：只能动人物说出口的话及为对白自然衔接所必需的紧邻叙述。不能重新处理人物合并、结构、世界观、伏笔、剧情、关系走向和其他已完成的专项。人物姓名、真伪判断、伤势、知情状态、时间、关键引述与图片引用均受保护。完整章节按原路径和原文件名输出；未改章原样保留。

**最终验收**：不是“改了多少句”，而是“新稿与原稿盲比时，哪些话真变顺了，哪些本来顺的没有被误改”。没有作者认可的试验结果，不要声称达到我人工校对的水平。
