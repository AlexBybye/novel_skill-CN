# 执行指令（修订版）：《没有人应该出生》人物对白全面重修

请将本次任务识别为**把小说中不自然的对白改成真实的人会说的话**。人物不是在发表观点、核对事实、执行流程或概括主题，而是在和另一个具体的人交流。

严格遵照 `novel-dialogue-humanize-zh/SKILL.md`，**首先读取 `references/editorial-calibration.md`**（含防误改三规则、交流主体与情绪连续性检查、作者撤销样本库），再按 `references/batch-protocol.md` 完成全量任务；具体病灶辨认查 `references/diagnostics.md`。`novel-coauthor-zh` 是背景 Skill，不得使用它的结构性改写功能扩张本轮权限。

本次重修优先解决：①专业腔、工作汇报腔、程序化交流；②文学化缩句、省略句、刻意精练的短句；③两个人像老学究一样反复核实、澄清、推理；④对话过度流畅、过度理性、过度有目的；⑤情绪衔接不真实、人物声音趋同、人情味不足。

## 三条最高优先级禁令

**禁令一：任何场景都不要专业腔。** 调查、救援、能力研究、组织工作、医学检查、行动安排等场景同样必须使用普通人自然说话的语言；不因角色是工作人员、研究人员或行动负责人就让他满口术语。重点清理：核验、复核、处置、对接、执行、观测、干涉、响应等不必要的专业表达；风险点、行动方案、信息闭环、证据链、工作流程、阶段性结果等报告式语言；“需要进一步确认”“目前无法排除”“根据现有信息”“按原计划执行”等机械陈述；一人汇报发现、一人确认结论、一人安排下一步的流水线式对话。人物可以知道专业知识、做专业工作，但用普通语言说清眼前的事。专业能力体现在观察、判断和行动中，不靠术语证明；即使某个术语在设定上正确，也不应默认让人物直接说出来。

> 不自然：“当前无法确认水源，需要进一步排查。”
> 自然：“闸都关了，水还在往上涨。我也不知道它从哪儿来的。”
>
> 不自然：“先确认人员状态，再执行下一步。”
> 自然：“他还能走吗？不行就先把人扶出去。”

**禁令二：禁止文学化缩句与刻意省略。** 不要把正常人话压缩成诗句、剧本提纲或行动标签（如“窗边画一道”“试泄水”“先看出口”“从这里开始”“能走的路，先留着”“人还在，东西不能丢”）。恢复具体的交流对象、自然语序和必要的口语连接。区分：**允许**“快跑！”“别动！”“我不是……我不知道该怎么说。”等因惊恐、迟疑、痛苦而真实中断的表达；**禁止**为文学感主动省掉主语、动作、对象或必要连接，把完整行动建议压成两三个词，用故作深沉的半句话代替正常表达，让人物频繁用整齐、有留白感的短句制造气氛。恐怖感应主要来自事件、环境和人物的反应，而不是靠对白写得神秘。

> 不自然：“窗边画一道。不碰这个，先看看它动不动。”
> 自然：“先别碰这个。你去窗户上画条线，过一会儿看看水有没有往下退。”
>
> 不自然：“试泄水。开一点，出了事关回去。”
> 自然：“要不先拧开一点试试？不对劲就赶紧关上。”

**禁令三：任何情况下禁止老学究式互相核实。** 绝不允许人物像审稿人、审计人员一样逐项确认事实、界定概念、纠正表述、整理逻辑。“所以你的意思是……”“准确地说……”“那至少可以确认……”“目前只能确认……”这类对话无论出现在日常、调查、争执、恐怖还是组织工作场景，都不允许保留。变体包括“你说的是A，不是B，对吗”“我没说A，我说的是B”“那我们至少能确认C”“不能这么理解，准确地说是D”“问题不在于A，而在于B”“你先回答我的问题”“这只能说明A，不能说明B”。这些句式单独偶尔可以是正常表达，但人物持续互相澄清、精准反驳和递进推理时即形成严重机械感，任何场景不得保留。处理原则：不让每个人都精准理解问题；不让每个问题都获得完整回答；不让人物主动纠正对方每一处不准确表述；不让人物随时准备总结已知事实；不让双方像辩论赛轮流提精确论点；不让谈话变成逐条完成的信息核对表。对方说了不够准确的话，人物未必在乎那点误差，可能直接说自己担心的事，也可能不接话。需要交代的信息可通过看到的东西、实际发生的事、自然的提问或叙述完成。禁止把机械核实简单改成机械反问、机械顶嘴或另一组工整短句。

## 场面级交流失真

逐场检查：人物是否为了推进剧情说了自己其实不想说的话；争执结束后情绪是否被无故清空；人物是否总能准确解释自己的动机；是否每个人都在主动配合下一步；是否存在本来可以沉默、回避、抱怨或由第三人接话的地方；不同人物之间的亲疏是否真正影响了说话方式。

参考作者亲自润色的第050章：周宁不想回答陶宜，由许棠接话；周宁仍在生气，却可以正常和许棠交流；许棠理解陶宜，也没有完全站在周宁一边。**不要复制“让第三人打圆场”这个固定动作，应学习为什么这个人物在这一刻不想回答。**

## 恢复真实的人情味

人物之间不必每句话都有信息价值。允许：顺着对方的话聊两句；吐槽、开玩笑、抱怨；说已经知道的事情；不太认真地回答；说着说着想到另一件事；关心别人却关心得笨拙；对亲近的人多说几句没用的闲话；不知道如何安慰，只能陪着。但不能为增加生活感强行添加闲话、语气词、喝水、看手机或打趣；真实交流不等于无意义交流越多越好。

## 人物表达必须有差异

不能让周航、周宁、许棠、陶宜、沈霁、王旭、陈砚以及其他人物拥有相似的推理能力和表达习惯。差异体现在：谁更愿意解释，谁更容易不耐烦；谁会开玩笑，谁不爱接话；谁喜欢关心别人，谁不愿意接受关心；谁说话直接，谁会绕开真正想问的事；谁在紧张时话变多，谁在紧张时话变少；同一个人面对家人、朋友、陌生人和敌人时如何变化。不能给人物机械分配口头禅，也不能强行让所有人变得笨嘴拙舌。

## 不同场景的执行重点

- **日常场景**：减少信息交换感，保留随意、亲近、琐碎和无须解释的交流。
- **争执场景**：不要像辩论赛。人物可以抓错重点、赌气、不服、沉默，但不要机械顶嘴。
- **情绪崩溃场景**：不要让人物完整分析自己的心理。保护真实的重复、混乱和无法表达。
- **调查、组织和专业场景**：严格禁止专业腔、报告腔和相互核实。让人物说看见了什么、担心什么、准备做什么，使用普通语言。
- **危险与恐怖场景**：保留必要的即时命令，但不允许文学式缩句、程序化分工、报告式讨论和概念澄清。人物的慌张、担心、行动和判断必须符合现场状况。

## 修改流程（四遍）

1. **整场交流诊断**：判断这场对话是否像真实的人在交谈。重点找出专业化、老学究式核实、交流过度顺畅，以及情绪连续性问题。
2. **重修交流结构**：必要时调整谁先说、谁不回答、谁接话、哪些解释根本不需要出现、哪些本来生硬的信息应改由叙述或实际行动承载。不得擅自改变剧情、人物立场和关系走向。
3. **逐句重修**：清理文学化缩句、倒装、工整排比、过度完整的自我解释、程序化语言和不符合人物口吻的表达。
4. **连续阅读**：重点问——这些人现在是在真正互相交流，还是换了一套更口语的词继续核对信息？若仍然像两个人轮流分析、解释和确认，即使每句话都很口语，也没有通过。

## 严格编辑边界

- 作者最新正文为唯一底稿。
- 不改变世界观、能力机制、事件因果及人物关系。
- 不大幅删减非对白叙述。
- 不破坏已有的恐怖氛围与生活细节。
- 保留自然的原句，杜绝为了修改数量而修改。
- 但不能因为单句没有明显病句，就放过整场交流的问题。
- 作者亲自修订的章节是校准样本，应学习编辑判断，不能机械模仿句式。
- 只能动人物说出口的话及为对白自然衔接所必需的紧邻叙述；人物姓名、真伪判断、伤势、知情状态、时间、关键引述与图片引用均受保护。
- 输出完整 Markdown 章节，文件名去掉版本数字括号，不添加额外后缀，并附逐项修改前后对照；完整章节按原路径输出，未改章原样保留。

## 最终验收标准

三个绝对要求：第一，无论什么场景，都不能让人物说一口专业报告腔。第二，不能使用文学化缩句、省略句和刻意精练的台词。第三，绝不能让人物像两个老学究一样，反复核实、澄清、纠错和推导结论。

最终评价标准不是对白有多精练，也不是人物有多聪明，而是：**他们说的话，是否真像有血有肉的人在各自的处境里，会对眼前这个人说出来的话。**
