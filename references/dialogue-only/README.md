# 长篇小说对白人类化专项 Skill

本目录可独立作为 `novel-dialogue-humanize-zh` 安装使用，或与 `novel-coauthor-zh 2.0.0` 配套。不是一次对白改写的结果，也不是人物设定档案；用户仍需把**最新正文**交给执行的智能体。

- `SKILL.md`：任务权限、优先级、自然化步骤及最终验收。
- `references/editorial-calibration.md`：**v1.1 核心更新**。优先用作者确认样本校准 AI 的保留/修改判断，禁止句式黑名单与伪口语配额。
- `references/diagnostics.md`：常见机械对白诊断、修法、例外与原创示意。
- `references/batch-protocol.md`：全书版本基线、全章读取、分批、跨章与交付。
- `scripts/verify_manuscript.py`：对比原文与精修目录的机械结构，不能给文学评分。
- `RUN_PROMPT.md`：可以直接复制给执行智能体的任务指令。
- `CORRECTION_PROMPT.md`：当其他 AI 把目标误解为“加废话、半截句、反问”时，直接发送的纠偏指令。

**关键**：全量是覆盖每章，非改写每章；事实唯一基准是作者指定的现行正文，不是模型的记忆或旧方案的章节描述。其他结构、人物、剧情专项已经完成，本 Skill 不替作者重做。

**v1.1 与 v1.0 的差别**：把“自然可说性 + 人工校对前后对照 + 有证据的最小修改”置于功能性分析之前，新增先试小样再扩展全书的质量闸门；没有真实作者校准，不能宣称达到作者手修水平。
