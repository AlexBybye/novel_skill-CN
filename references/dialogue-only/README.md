# 长篇小说对白人类化专项 Skill

本目录可独立作为 `novel-dialogue-humanize-zh` 安装使用，或与 `novel-coauthor-zh 2.0.0` 配套。不是一次对白改写的结果，也不是人物设定档案；用户仍需把**最新正文**交给执行的智能体。

- `SKILL.md`：任务权限、优先级、自然化步骤及最终验收。
- `RUN_PROMPT.md`：可以直接复制给执行智能体的任务指令。**v1.2 起为作者 2026-10-29 重修指令修订版**：三条最高优先级禁令（任何场景不要专业腔；禁止文学化缩句与刻意省略；禁止老学究式互相核实）、五类场景执行重点、四遍修改流程、严格编辑边界与最终验收。
- `references/editorial-calibration.md`：**v1.2 核心转向**——由“识别不自然句式”升级为“判断哪些该修、哪些真实的不完美必须保留”；含防误改三规则、交流主体与情绪连续性检查（两问框架）、作者认可修改的六条编辑方向与作者撤销样本库。
- `references/diagnostics.md`：三条最高优先级禁令的词表与反例、常见机械对白诊断、修法、例外与原创示意。
- `references/batch-protocol.md`：全书版本基线、全章读取、分批、跨章与交付。
- `scripts/verify_manuscript.py`：对比原文与精修目录的机械结构，不能给文学评分。
- `CORRECTION_PROMPT.md`：当其他 AI 把目标误解为“加废话、半截句、反问”时，直接发送的纠偏指令。

**关键**：全量是覆盖每章，非改写每章；事实唯一基准是作者指定的现行正文，不是模型的记忆或旧方案的章节描述。其他结构、人物、剧情专项已经完成，本 Skill 不替作者重做。

**版本沿革**：v1.1 把“自然可说性 + 人工校对前后对照 + 有证据的最小修改”置于功能性分析之前，新增先试小样再扩展全书的质量闸门。v1.2 依据 17份终稿对照（14章一致、19/21处修改保留、2处撤销）确立防误改三规则与撤销样本库；依据第050章人工修订确立“两问框架”与交流主体与情绪连续性检查；吸收作者重修指令修订版的三禁令、五场景与四遍流程。没有真实作者校准，不能宣称达到作者手修水平。
