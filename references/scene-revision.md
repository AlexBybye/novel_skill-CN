# 全章场景精修

用于已获授权的全章、连续章节或全书对白精修。以[人物对话](dialogue.md)为基础，处理人物怎样在场景里相处，不把小说改成更顺口的台词集，也不统一重写其他文风。纯诊断只指出问题；重大因果、死亡、关系成立、能力和谜底仍按主入口守住授权。

## 先完整读，再决定哪里改

读取当前稿、适用个人卡及关系和知情时点。完整读本章，从一场交流开始之前读到结束之后：人在哪里，正在做什么，身体怎样，想要什么，环境怎样被注意，谈完后留下什么。跨章同一场接读，前章已展示的操作、规则和态度不能当成未发生。不能只检索引号、挑几处高频词或沿用上轮“已修”名单。

为本次精修的各场留一张简短场景卡，放在已有工作记录或当前写作准备中，可用一行连写；不在正文展示，也不另建每场一个文件：

| 项目 | 需要弄清的内容 |
|---|---|
| 表面话题 | 人物眼下谈的具体事情，以及正在共同经历的活动和环境。 |
| 各自真实目的 | 每人希望眼前人怎样回应；事实问题对本人有什么用，也允许只想闲聊。 |
| 不愿承认的事 | 若确有依据，记欲望、恐惧、羞耻、面子或依赖；没有就留空，不强造秘密。 |
| 关系影响 | 熟悉程度、旧情绪、权力和知情差异怎样影响说到哪里、接哪半句。 |
| 情绪转折 | 真正改变谈话方向的具体话语或行动；没有明显转折照实记录。 |
| 结束方式 | 已解决哪一部分，还是有人不肯继续、事务打断或转入共同做事；什么余波仍在。 |

卡是编辑理解人物的工具，不是要求人物把六项说出口的提纲。检查与核验由编辑在幕后完成，不能为了证明守住边界，让角色反复核查已知事实。

## 三类谈话分别修

| 场景 | 优先处理 | 需要保留 |
|---|---|---|
| 亲密关系与私人争执 | 从“纠正你是什么意思”回到本人在意什么、想得到什么、受了哪种伤。允许有依据的偏心、赌气、嘴硬、占有、回避和说不圆；不要把情绪逐条讲明、轮流划责后妥善结束。 | 已定关系和人物底线，直接表达、必要解释、真正的理解与和解；不靠新增决裂或强制失控制造生命力。 |
| 调查、质问与审讯 | 分清各自想得到、能交付、想藏住的信息。提问、辩解、沉默与交换随对方回应变化，关键回答须有落点；共同已知背景不再逐项考试。 | 必要证词、关键原话、证据先后、权力压力与角色有理由的严谨；不能以少流程删掉破案依据。 |
| 危险中的协作 | 只说当时确实需要让别人知道、而对方无法自行看到的事，以及即时警告、求助和选择。撤掉台词对刚发生动作和刚解释规则的复读，让身体、空间、注意与判断承担过程。 | 必要指令、空间因果、能力条件和真实的惊慌重复；不把所有人改成训练一致的救援队，也不让人无故失去常识。 |

一场可以转换类型。日常闲聊不必硬套争执、潜台词或关系转折；调查和工作中的理性本身不是错误，私人情绪也不必一律含糊。

## 纯功能性对白与重复操作

沿完整章群检查“观察—核实—商量措施—分工—照做—复述结果—整理记录—安排下次”是否在不同人物和副本里反复占据前景。单步合理不能豁免累积的整齐。逐处辨认：

- **真正需要当场确认的事**：对方不知道、听错会有具体后果，或确认本身正在施压、索取承认、表现恐惧。保留必要的可读过程。
- **编辑在检查而人物不必再说的事**：刚交代过的人数、物品、路线、风险和权限又轮流确认，只为填信息。依据现场可见性删去重复，必要时概述；不能偷移角色未知的信息到限知旁白。
- **重复操作有新代价**：同一动作因伤势、失败、时间压力、人际冲突或异常变化而有不同体验，留住变化及必要步骤；没有新阻碍的登记、复制、收材料、清点和交接可合并、略写或从结果入场。关键原件去向、先后、能力使用与伤情因果仍须可追溯。
- **事件后的生活**：善后可以需要工作，但不默认以“记下、核查、明天再安排”结束每段经历。保护原有的疲惫、庆幸、没缓过来、吃饭睡觉、私人牵挂和未说完的话，不再用总结把它们解释完整。

不要把删除流程后的空位统一填成闲聊、新支线、争吵或怪动作。已成立的恐怖体验、生活细节、伦理分歧和闲笔须保护；恐怖不只剩规则说明和脱困方案。需要重大事件重排才能解决时，记具体结构缺口，不临时编造谜底。

真正的闲谈、陪伴与普通生活不因没有新信息就缩成“他们聊了一会儿”；精修要保护其具体内容和相处过程。减少的是反复交付同一功能，不是把小说压成更短的任务摘要。对白被削成抽象短句时，回到[口语完整性](dialogue.md#口语完整性与精修优先级)恢复人会说的话，不继续凝练。

信息与动作拥挤的危险场景，先核清当时能看见、听见与来得及做什么，再安排读者需要经历的瞬间。保住失措、身体负担和选择的分量，规则不在每次行动前后重讲；也不为提速删掉使险境成立的空间与先后。不把组织知识、职责说明和世界观讲解塞进所有空隙，依[认知路径](dialogue.md#信息分层与认知路径)分层处理必要内容。

## 动作、心理和环境一起改

动作跟随真实活动及时间延续，不每句话配一次喝水、抬眼、摸杯沿、摆衣角、点头或攥手。人在洗碗，是饭后确实有碗要洗；这件事可以跨几轮继续，不用每轮重启。环境可以影响听觉、注意和身体，也可以只是让读者停留在此处，不强迫每一处都推进主线。

遇到机械交流，先改人物为什么说、怎么听和怎样继续；补动作不能替代这一步。删掉重复解释台词的心理时，保留独有的念头、矛盾、视角偏差与情绪重量；不把私有心理改成别人听得见的话，也不统一用小动作代替心理。不把“专业、成熟、克制”当成所有人在所有情境里的共同上限。

配角的独立性看他怎样坚持、拒绝、偏私、判断和付代价，不靠补履历、增加姓名或给每人一项分工。死亡后的余波来自这人已经怎样活过、怎样待过别人；不能为催泪临时补造往事或改动死亡因果。

全量精修若发现一段情节铺开大量角色，先按[人物设计](character-design.md#从人物卡到对白)查看旧卡与实际出场，考虑复用或集中承担合适情节；同一段集中引入新人不超过4名。现有角色的合并、删除或职责迁移若牵动证词、死亡、关系、知情和因果，按本次授权处理，不能为人数达标直接改掉既定事实。少量角色仍须有独立选择，不能只是把一群工具人的台词压给一个人。

## 完成证据与下一段

每章仍先查情节设定，再另读完整场景查对白与人物行为，按[双次审查](event-progression.md#交付前分两次审查)留下实际依据。第二遍同时读动作、神态、心理和环境；只列台词变更、核对引号或跑过脚本不算全章完成。自然场景可记“整场读后保留”，但须说明保留的具体相处，不用一排“通过”代替判断。

批次记录分开写完整读审范围、实际改稿范围、仅查承接范围、未完成范围。按[跨章观察](narrative-variation.md)复查相邻场景的重复流程与收尾；支线的阶段兑现另按其收束方法记录，不能以本章话说清楚冒充悬线已有答案。尊重作品现行版本、备份与Git约定，不因通用流程重复复制稿件或动暂存区。
