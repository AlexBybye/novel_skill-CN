# 首稿文学效果基准（协议就绪，A/B/C/D尚未执行）

本文件提供固定输入与评阅方法，不是已通过的文学测试。以下情境为原创，未进入对照范例库；不使用提炼范例的小说段落做主要测试。单元测试通过只说明取材与隔离机制可用。

## 冻结条件与分组

升级前先保存当前工作副本及hash，不能只取较旧的Git提交充当原版（工作树可能已有更改）。A/B用该冻结副本，C/D用升级版本；同一模型、宿主、相同用户输入、输出预算和可控生成参数，固定可用参数并记录不可控项。各组使用独立新上下文，不能把上一组结果或评阅标准传进去。

| 组别 | 提供材料 | 用途 |
|---|---|---|
| A | 冻结原版入口与它按任务加载的参考 | 原版表现 |
| B | 与A相同，另给同一范例库中最相关1—3组完整对照；不加新版流程 | 范例本身的贡献 |
| C | 新版入口、按场景实际选择的完整范例及体验连续性复核 | 整体改动 |
| D（可选） | 新版流程，明确本轮无范例可用，不补造 | 工作流本身的贡献 |

B组预选：PB-01→EX-001，PB-02→EX-004，PB-03→EX-003，PB-04→EX-006，PB-05→EX-002，PB-06→EX-004，PB-07→EX-005，PB-08→EX-001。C组允许选不同组或不用，但记录实际ID、全文hash、理由及排除条件。B/C采用同一库，避免“更好的材料”和“更好的流程”同时变化却无法分辨。

每组至少每场一份完整原始输出；条件允许做两次以上独立重复，记录波动，不因某一稿特别好便挑选展示。保留首稿与自审后的最终稿、工具调用及材料清单；如宿主不提供首稿，不声称比较了它。记录日期、模型标识、参数、基线hash、提示全文和是否访问外部资料。

## 固定生成输入

每条输入均可单独交给生成者，不把下一节的评阅要点混入提示。它们只授权虚构测试片段，不授权修改真实小说。保持人物名、事实边界和各场长度范围，各组一致。

### PB-01 平静日常

写250—400汉字。第三人称贴近退休的夏老师，她独自在菜市场选蘑菇，今天没有急事，喜欢辨不同菌子的气味。文风舒展、允许长句与明确心理，不制造事故、伏笔或冲突。结束时她仍在摊前挑选，不必总结人生。

### PB-02 熟人对话

写250—400汉字。常一起踢球的丁原和阿卓在洗球衣。丁原怕衣服掉色，却嘴上说随便洗；阿卓觉得他事多，爱拿他开玩笑。两人都想早点洗完回家。关系一直友好，不新增重大往事、固定口头禅或争吵，不要求说出彼此理解。

### PB-03 陌生人互助

写250—400汉字。夜间公交终点站，年轻的季禾愿意陪第一次来此的旅客去问路。旅客能自己走，担心麻烦人，又怕跟错人；季禾也想赶快去吃饭。两人互不相识，没有危险、骗局或关系升级。写到他们走向值班室，不补出旅客的亲属经历。

### PB-04 疲劳与不耐烦

写250—400汉字。糕点师周明连做两场宴席后回店，合伙人把一份退单消息漏发给他，导致他多做了一盘点心。合伙人承认漏发，但觉得他当众发火过头；周明知道自己话重，现在仍很烦。今晚没有和解，也不决裂，不新增更大的损失。文中保留人物直接说烦的可能，不要求用动作代替心理。

### PB-05 紧张行动

写250—400汉字。舞台停电，演员叶笙要沿熟悉的后台台阶带一位紧张的新演员走回休息间。她知道路线，但看不清每一级；对方拉着她的戏服袖口。两人最终平安到达。限知叙述，不新增追逐、坠落、伤势或超常现象，不把每一级都拆成同样的短句。

### PB-06 亲密关系

写250—400汉字。相处多年的伴侣在整理旧唱片，明天一人要出差一周。甲想把一首歌听完，乙想赶紧整理完睡觉，两人亲近，也都知道出差安排。不新增表白、分手或秘密，不要求触碰身体。关系从听唱片和收拾的相处中呈现，允许直接说想念。

### PB-07 冲击后的普通环境

写250—400汉字。方遥刚得知工作多年的工厂将关闭，独自坐地铁回家。她尚未告诉家人，仍要下车买晚饭。以她此时的感受写，允许长内心；不擅自让她立刻乐观、不新增家庭疾病或求职成功，不强设象征物。结束时事情仍未想通。

### PB-08 内省与概括

写250—400汉字第一人称。叙述者在整理旧邮件后想起与一位朋友慢慢疏远的过程，具体原因只有两人作息和兴趣渐渐不同，没有背叛，也没有最后一次争执。文风平缓，允许概括、反复、明确判断和长句。今晚不重新联系，不用等待、手抖或一个象征物制造结尾。

## 盲评与证据

先隐去版本、组别、范例ID及自评说明，随机编号；编号映射由组织者另存。让作者或未参加生成的评阅者先回答“哪一版更愿意继续读，为什么”，再按下列维度引用具体句段。揭盲前不告诉评阅者哪种机制是升级目标；平局和各有优点有效，不强迫胜负。

| 维度 | 需要的文本证据 |
|---|---|
| 阅读驱动力 | 指出想接着读的句间牵引或想跳过的位置，不能只说更生动 |
| 人物真实性 | 私人需要、注意、不成熟或单纯快乐怎样影响取舍 |
| 对白自然度 | 话怎样由实际听到的内容产生，是否在轮流陈述正确观点 |
| 体验连续性 | 一个未完动作、感觉、判断或情绪怎样进入下一处，是否过早交付结果 |
| 文风保持 | 长句、内省、粗粝、幽默或舒缓气质是否保留；不能把短句多判为更好 |
| 忠实性 | 是否越过已定事件、结局、关系、视角或知识边界；重大越界单列，不用文笔掩盖 |
| 过拟合 | 是否跨场复现示例道具、接触顺序、句式或统一的准确理解；按机制判断，不用禁词计数 |

记录每个维度的“较好／相当／较差／无法判断”和原文证据，可附总偏好，不用单一总分替代证据。PB-01/08尤其用于检查是否把平静、概括和长内心错误改成动作悬念；PB-04检查是否被自动修成道歉与共识。风格测试没有作者样本时，只能判断是否遵循本条文风要求，不能声称还原了某位作者声音。

结论至少区分：材料选择是否正确、编写者自查的生成表现、独立盲评的结果、未验证的假设。当前会话同时读过新旧规则后的示范试写，只能作适配冒烟，不能算A/B/C因果证据。未运行独立模型实验时，就保持本文件状态为未执行；不为填表捏造输出、盲评人或作者认可。
