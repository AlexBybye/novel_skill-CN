# 直接使用：一稿一修的两次指令（示意）

> 这只是便于跨助手调用的**简短指令外壳**；技能正文仍以 `SKILL.md` 为入口。作者给的本章大纲、角色卡、上一章实际正文、不可改事实必须随任务提供或有权读取。没有材料不要编造已知事实。以下提示不含任何作者未发表小说内容。

## 第一轮：按既定大纲完成可读的初稿

```text
使用 novel-coauthor-zh，按已确认大纲写出完整章节，先通读上一章和有效的人物、关系、时序、能力设定。

不要先生成流水账式事件骨架，再均匀补对白、心理、衣着和景色。首稿就让人物拥有连续的心理生活，允许不体面的念头、非功利日常和完整自然的交流。维持真实的身体外貌与当天形象，场景有可想象的空间、季节和生活背景。让读者在意人物之后才让重大事件发生；写完要保留事件的情感余波。

写完内部执行：事实/设定核验一遍，六维阅读体验通读一遍。不要为满足指标机械增加长对白、独白、夕阳或章末悬念。仅交完整章节及必要的未决事实，不输出自我表扬或六个分数。
```

## 第二轮：围绕真实缺口进行场景级精修

```text
使用 novel-coauthor-zh 的六维质量标准和一稿一修流程。完整通读本章与相关前后文；先标出已经非常好的心理、对白、情感钩子、人物外形与环境场景，它们要保护。

再找真正影响连续阅读的几处问题：人物内心是否只有情绪标签；对白是否是不断问答与核对；角色是否只在危险时鲜活；日常景色是否只有背景板；事件高潮有没有铺垫与后果；跨章节是否反复同一流程或出现设定、知情错误。

按完整场景修复最严重的问题，不做一遍全章机械换句或平均扩写，不改既定重大事件与人物关系。修后对照原文，如出现心理说明书、人人话多、删掉有价值的日常、服装/世界观不一致，就撤回相应改动。

最后再核事实与六维体验。交完整修订稿，以及简短说明哪些场景实改、哪些保留、哪些仍待作者确认。没有充分证据，不宣称两轮已经达到出版级。
```

## 不宜拿这两个指令处理的情况

- 只要求对话自然化：改用技能中的对白专项入口，不能借第二轮全面补场景。
- 只要求诊断：给诊断，不能自动生成修稿。
- 缺少已锁定大纲或能力边界，关键故事结局必须靠猜：先指出未确认的根本冲突，不以“第二轮完成”为目标乱写。
- 多章存在同型流程：需要先做跨章节奏调整，不是对每章分别补心理就能解决。
